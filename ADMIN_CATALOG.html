Veröffentlichung auf GitHub (Commit Flow)

Kopieren Sie die exportierten Dateien nach F:\DeutschThek\data\ und führen Sie folgende Befehle aus:

# 1. Heruntergeladene Dateien in das Projektverzeichnis verschieben (PowerShell): Move-Item -Force "$env:USERPROFILE\Downloads\official-catalog.json" "F:\DeutschThek\data\official-catalog.json" Move-Item -Force "$env:USERPROFILE\Downloads\official-catalog.js" "F:\DeutschThek\data\official-catalog.js" # 2. Synchronisieren & auf GitHub pushen: git add data/official-catalog.json data/official-catalog.js git commit -m "Update official document catalog" git push origin main
